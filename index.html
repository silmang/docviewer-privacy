처리하는 정보와 목적

문서뷰어는 사용자가 선택하거나 접근 권한을 허용한 문서를 기기에서 열고 표시하기 위해 접근합니다. 앱은 인터넷 권한을 선언하지 않으며 문서나 사용 정보를 개발자 또는 외부 서버로 전송하지 않습니다. 광고·분석 SDK도 포함하지 않습니다.

기기 내 저장과 보관

최근 문서, 즐겨찾기, 보기 설정은 다시 열기와 앱 기능 제공을 위해 기기에 저장됩니다. 최근 문서 목록은 앱의 최근 문서 목록 비움 기능으로 지울 수 있고, 즐겨찾기는 앱에서 해제할 수 있습니다. 앱을 삭제하거나 Android 설정에서 앱 데이터를 지우면 앱 내부에 저장된 기록과 사본도 제거됩니다.

암호가 설정된 문서의 암호는 문서를 여는 동안에만 사용하며 저장하지 않습니다. 복호화한 임시 파일은 앱의 캐시에 두고 문서를 닫을 때 삭제합니다. 앱이 예기치 않게 종료되어 남은 임시 파일은 다음 실행 때 정리합니다.

파일 권한과 공유

Android의 모든 파일 접근을 허용한 경우 앱의 파일 탐색기에서 공유 저장소의 문서와 폴더를 찾을 수 있습니다. 이 권한은 Android가 공유 저장소에 대한 읽기·쓰기 접근을 허용하지만 앱은 원본 문서를 수정하거나 삭제하지 않습니다. 허용하지 않아도 Android 시스템 파일 선택기로 사용자가 고른 파일과 폴더를 열 수 있습니다.

사용자가 앱에서 공유 또는 내보내기를 선택하면 선택된 다른 앱이나 Android 인쇄 기능으로 파일을 전달할 수 있습니다. 전달받은 앱의 정보 처리는 해당 앱의 정책을 따릅니다. 문서뷰어는 이 동작 외에 파일을 외부로 전송하지 않습니다.

제3자 제공, 광고, 계정

앱은 사용자 정보를 수집·판매·공유하지 않으며 광고를 표시하거나 계정을 만들지 않습니다.

문의 및 정책 변경
